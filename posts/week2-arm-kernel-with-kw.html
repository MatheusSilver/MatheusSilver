Building and booting a custom Linux kernel for ARM

Objective

This week we explored the Kernel Workflow Tool (kw), which helps simplify the process of building and booting the Linux kernel from source.

The tool also offers quality-of-life features for working with the virtual machine, such as ssh access and file transfer from the host machine.

Challenges

Since I was still learning how to configure environment variables, some kw features, such as kw ssh, did not work at first.

We also found an outdated instruction in the tutorial regarding the Linux version to install. During the hands-on session, one of the monitors helped our group understand version distribution and select the correct version.

Experience

Compared with last week, I solved variable-related issues much faster, especially those involving vdaX and initrd. During the hands-on session, we also learned a few terminal productivity tricks.

These shortcuts, such as CTRL+R, are not essential features, but they make development sessions significantly more comfortable.
