Introduction to Linux kernel build configuration and modules

Objective

The goal was to prepare a simple custom module and include it in the Linux kernel build, so we could better understand how modules add functionality without requiring a full system rebuild.

Challenges

This week, several students and I faced the same issue: after customizing the Linux version name, the terminal stopped displaying messages correctly. However, we could still access the virtual machine through ssh.

Experience

In terms of content, this was the tutorial I found most interesting, because it clarified part of the mechanism behind Linux customization.

Last week I had trouble with kw ssh and used a workaround. This week I understood how to use it properly and became more familiar with the tool.
