Choosing an Issue to Work on in the Kernel

Discussion

This week, my classmate and I discussed what kind of issue we should work on. I suggested an issue related to code quality, since it was simpler to work with, and I also had prior scientific initiation experience in this area. As such, we decided to work on code duplication in an Arduino chip driver, where the exact same switch-case statement was repeated four times, once for each light level.

The file we decided to work on is in the Linux source tree under the IIO light drivers.

Also, since other classmates were still trying to decide, we did a small sub-curation of the TA's list to help them select their issues.

And that is it, nothing particularly special happened this week.
