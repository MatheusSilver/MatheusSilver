Setting up a test environment for Linux Kernel Dev using QEMU and libvirt

Objective

Testing new kernel features can break the host system, so this week we focused on preparing an isolated environment for safe Linux kernel development.

Challenges

The tutorial itself went smoothly. However, due to my lack of experience with virtual environments, I had some difficulty understanding variables such as rootfs, kernel, and initrd.

I was not able to fully solve this issue during the week, so I decided to revisit it in the following week to better understand the role of each variable.

Experience

I am also a newcomer to Linux, so this first week was useful for learning basic tools such as VIM and NANO. Even so, I still prefer using VS Code for more complex development tasks.

Even though we mainly followed the tutorial, it was still valuable to apply concepts from the Operating Systems course in a practical setup.
